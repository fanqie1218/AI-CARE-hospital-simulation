# AI-CARE 病房夜间高危巡检机器人 - 医院模拟VR巡检系统

基于边缘端AI视觉与多模态融合的病房夜间高危行为智能巡检机器人虚拟仿真系统。

## 功能特性

- **20间病房巡检**：模拟真实医院病房布局，机器人自动定速巡航
- **点击导航**：鼠标点击任意病房，机器人快速移动前往
- **病人状态模拟**：7种状态（睡眠→醒来→坐起→探腿→站立→坠落中→已坠落）
- **骨骼检测可视化**：17关键点 COCO 拓扑结构实时绘制
- **PID 控制算法**：带死区电压补偿与积分分离的增量式 PID
- **互补滤波**：IMU 与编码器 98%:2% 融合航向校正

## 技术栈

- 纯前端 HTML + CSS + JavaScript
- Canvas 2D 渲染引擎
- CSS Grid 三栏布局

## 项目背景

全国大学生机器人及人工智能大赛参赛作品
